# Pochy MotorBike

Landing page del taller de motos **Pochy MotorBike** en Medellín, Colombia.

Presenta la marca, los servicios del taller, la opción de financiamiento con Addi, la ubicación y el contacto directo por WhatsApp. Incluye versión en español e inglés, animaciones suaves y un diseño pensado para verse bien en móvil y escritorio.

## Qué incluye

- Hero con la identidad de la marca
- Catálogo de servicios con CTA a WhatsApp
- Sección de financiamiento Addi
- Motivos para confiar en el taller
- Ubicación, horarios y enlace a Maps
- Botón flotante de WhatsApp

## Stack

Astro · React · Tailwind CSS · Framer Motion · TypeScript

## Cómo correrlo

```bash
npm install
npm run dev
```

Otros comandos: `npm run build`, `npm run preview`, `npm test`.
